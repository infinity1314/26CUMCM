# 25-point strategy without the center station

This is the complete snapshot of the certified 25-station strategy before
testing a different 25-station layout. It is the 26-station route with the
origin `(0,0)` removed. The snapshot was created on 2026-09-11 before any
outer-station deletion was applied.

`cumcm_robot_25_without_center.exe` is self-contained. The strategy and
geometry Python files are included as source snapshots, together with the
inspectable policy, verification program, and modeling report.

No official simulator was started while creating this backup.
