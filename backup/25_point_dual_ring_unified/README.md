# 25-point dual-ring unified executable backup

This directory is an immutable snapshot taken before splitting the question 3
and question 4 executable entry points on 2026-09-11.

The backed-up `cumcm_robot_unified.exe` requires `--problem 3` or
`--problem 4`. Its question 4 search layout contains the origin, 12 stations
on the 980 m inner ring, and 12 stations on the 1875 m outer ring.

`SHA256SUMS.txt` records the checksum of every snapshotted file.
